# Contributing to FilterAniX

Thank you for your interest in contributing to FilterAniX!

## Development Workflow

1. Fork the repository and clone your fork.
2. Create a new feature branch (`git checkout -b feature/amazing-feature`).
3. Install development dependencies:
   ```bash
   pip install -r requirements.txt
   pip install pytest pytest-cov
   ```
4. Implement your changes following PEP 8 guidelines.
5. Run the full test suite to ensure 100% test pass rate:
   ```bash
   python -m pytest tests/
   ```
6. Commit your changes with clear, semantic commit messages.
7. Push to your branch and open a Pull Request.
